# 균형젤 / Countergel

한 번 베어, 양쪽 무게를 맞춰라

One cut. Balance both halves.

- 플레이 / Play: https://laika365.vercel.app/play/countergel
- 작품 노트 / Notes: https://laika365.vercel.app/games/countergel

## 한국어

젤의 씨앗과 기포를 읽고 한 번의 절단으로 두 조각의 질량을 맞추는 균형 실험입니다.

### 조작

젤이 빛날 때 무게 중심을 세로로 한 번 베세요. 12개를 맞추고, 3번 무너지면 끝납니다.

## English

Read the seeds and bubbles, then balance both gel halves with a single cut.

### Controls

When the gel glows, cut vertically through its center of mass. Balance 12; three collapses end the run.

## 로컬 실행 / Run locally

```bash
git clone https://github.com/rapina/laika-game-countergel.git
cd laika-game-countergel
npm ci
npm run dev
```
